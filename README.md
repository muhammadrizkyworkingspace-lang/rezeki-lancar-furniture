# Rezeki Lancar Furniture — Jepara Woodworks

Website katalog & database 500+ produk mebel kayu solid Jepara (Kayu Jati, Mahoni, Mindi, Rotan).

## Fitur Website
- **Real-time Search:** Filter produk instan berdasarkan nama, kategori, atau dimensi.
- **500 Produk Bersih:** Foto studio resolusi tinggi tanpa watermark.
- **Direct WhatsApp Ordering:** Tombol beli otomatis menyertakan nama produk & ukuran.
- **B2B Mitra Arsitek:** Form & alur konsultasi gambar kerja CAD/SketchUp untuk penawaran RAB.
- **Ultra Cepat:** Static single-page (HTML5 + Tailwind CSS + Vanilla JS), 0 database, loading < 0.3 detik.

## Struktur File
- : Website katalog statis siap deploy (GitHub Pages / Cloudflare Pages / Vercel).
- : Database JSON 500 produk lengkap dengan dimensi, material, finishing, dan harga pasar.
- : Format spreadsheet untuk Microsoft Excel / Google Sheets.
